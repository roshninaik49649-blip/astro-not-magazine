MISSION M01

Catch a transiting planet

Estimate the planet's radius from the dip it makes in starlight.

SIMULATED — synthetic light curve (fixed seed 20500116), not a real observation. Flux is normalised; time is in days.

1 · The reference light curve

Reference transit depth: 1.56 % (dip minimum)

2 · Your turn: drag the planet radius

Slider sets the radius ratio; the model curve updates. Use arrow keys for fine steps.

Model depth = (R_p/R_s)² = 1.56 %

3 · The algebra

depth ≈ (R_p / R_s)². So R_p / R_s = √depth = √0.0156 ≈ 0.125. For a Sun-sized star (696,000 km), that is a planet of ≈ 87,000 km radius — a sub-Neptune.
